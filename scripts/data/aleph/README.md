# Accepted aleph design sources

These GLIFs preserve Myia Didot Italic and Bold Italic ℵ as reviewed on
2026-10-25, including the Bold Italic lower-tip and upper-join repairs.
They derive from Old Standard (Alexey Kryukov; SIL OFL, see OFL.txt).
They are fixed design inputs for `scripts/upright_aleph.py`, independent of
regenerated UFO output. They are not a second copy to regenerate from the
roman: changing the approved design requires deliberate review here.

The accepted roman fit removes the 15.2-degree shear and stretches the
-23..1099 ink bounds to 0..1434, retaining horizontal dimensions. The
smaller upright versions retain their original height. Optical weight
was accepted in `proofs/upright-aleph-height-comparison-2026-10-25.pdf`.
