# Myia Didot — working notes for Claude

Fork of Theano Didot (akryukov/theano) aiming at full Latin-script, Greek and
basic Cyrillic coverage in Regular/Italic/Bold/Bold Italic with real small
caps. Phases and the coverage target: README.md, FONTLOG.txt,
`scripts/coverage.py` (`TARGET`).

## Ground rules

- **`sources/*.ufo` is the master.** Never run `make reimport` or the import
  scripts (`sfd_export.py`, `postprocess_import.py`); they overwrite every
  edit since the import. `sources/upstream/` is read-only reference.
- Change glyphs with scripts (ufoLib2) where possible; the person may edit the
  same UFO in FontForge or Fontra. After any UFO change: `make normalize`.
- **Italic, Bold and Bold Italic are generated** (`make_italic.py`,
  `make_bold.py`): change them only through the Regular or their generators
  (a recipe, a constant), never by editing the generated UFO, or the next run
  undoes it. `make reproduce` (≈40 s) lists what would change; run it before
  committing. Hand-drawn Italic exceptions are marked "drawn"
  (org.myiadidot.italicSource).
- Composites, small caps, derived letters, the smcp/c2sc block in
  features.fea are generated by their scripts (`docs/claude/glyphs.md`):
  rerun the script, never hand-edit their output.
- The working copy is in a synced folder: after big generation runs check
  for "(conflicted)" copies and lost glyph files (`scripts/sync_check.py`).
- `make winmetrics` after adding tall or deep glyphs.
- Hinting is generated at build time, nothing in the UFOs.
- Run Python as `.venv/bin/python -I`. Shaping defaults to German here
  (no f-ligatures): pass `--language=en`.

## Quality principles (in full: `docs/claude/quality.md`)

- Build a derived glyph from its final base in the same style.
- Never embolden or weight a combined shape whole: base and piece apart.
- One source of truth per decision; generate one setting from the other.
- Check glyphs against each other (base, kind, NFC/NFD, styles), not only
  one by one.
- Reference fonts are a calibrated range, not a target.
- After a change meant for some glyphs, sweep for side effects
  (`make diffenator`, `make regress`) before accepting a baseline.
- Metadata fails silently: categories, glyph and lookup order, code points.
- Verify geometry operations; regenerate whole styles, never copy glyphs
  between UFOs.
- The tools find candidates; the person's eye decides.

## Tests

- `make test` (≈90 s) runs on every commit via the pre-commit hook; with
  `make reproduce` a commit takes ≈2–3 min: give `git commit` a Bash timeout
  of 600000. If it times out, run the same commit again (it waits for or
  reuses the run; `MYIA_RECHECK=1` forces one).
- Exception lists in `tests/data/*.txt` only shrink; fixing an entry =
  deleting its line.
- When a test fails, find the cause first (`make regress`,
  `scripts/nfd_debug.py`). Only for an intended change regenerate baselines
  with `scripts/update_test_data.py` and say in the commit what and why.
- Never commit with `--no-verify` unless the person asked for it.

## Working economically

Token budgets run out on this project; keep the expensive model for
analysis, design decisions and new tools, and hand the loops to the project
agents (`.claude/agents/`):

- `font-runner` (Haiku): `make generate`, tests, `make reproduce`, `make
  otf`/`proof`, baseline updates you name exactly. Reports pass/fail and
  failing names only.
- `font-measure` (Haiku): strokes.py, derived.py, checks.py, glyph_lint.py,
  greek_pairs.py, `make pairs`, `make regress`: returns a short table and
  the paths of the full reports.
- Searches through the code: the built-in Explore agent.

Write long outputs to files and grep them; render only the glyphs in
question, small. One task per session (`/clear` between tasks): CLAUDE.md
and git hold the state.
