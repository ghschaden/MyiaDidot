# Sources

What is in this folder, where it came from, and under which license. All
font material here is under the SIL Open Font License 1.1; the copyright
lines are collected in [../OFL.txt](../OFL.txt).

## The masters

| Path | What it is |
|---|---|
| `MyiaDidot-Regular.ufo` | The master. Edited directly, by scripts or by hand. |
| `MyiaDidot-Italic.ufo` | Generated by `scripts/make_italic.py` from the Regular and Old Standard Italic. Hand-drawn exceptions are marked `org.myiadidot.italicSource: drawn` and kept. |
| `MyiaDidot-Bold.ufo` | Generated by `scripts/make_bold.py` from the Regular. |
| `MyiaDidot-BoldItalic.ufo` | Generated by `scripts/make_bold.py` from the Italic. Hand-drawn exceptions are marked `org.myiadidot.drawn` and kept. |
| `drafts/Italic-smallcaps.ufo` | FontForge's small-cap drafts for the Italic, made by `make_italic.py`; an intermediate, not edited. |
| `glyph-renames.json` | The `afii*` → `uniXXXX` renames applied when the Regular was imported. |

Change the generated styles only through the Regular or their generators
(see [../CONTRIBUTING.md](../CONTRIBUTING.md)); `make reproduce` checks
that they are what the generators make.

## Incorporated material

These sources contribute outlines to the fonts.

| Path | Origin | License | Used for |
|---|---|---|---|
| `upstream/` | Theano Didot Regular by Alexey Kryukov, 2007–2011 ([akryukov/theano](https://github.com/akryukov/theano)): the FontForge source, its FONTLOG, license and build script | OFL 1.1, Reserved Font Name "Theano" | The Regular, imported once (2026-10-14) as the master's starting point. Read-only since; `make reimport` would overwrite the master. |
| `oldstand/` | Old Standard Italic by Alexey Kryukov, 2006–2008 ([akryukov/oldstand](https://github.com/akryukov/oldstand), commit in `oldstand/COMMIT`): its SFD, a UFO conversion (`make oldstand`), FONTLOG, README and license | OFL 1.1 | The italic letterforms: `make_italic.py` takes Old Standard's italic letters, adapts their weight, spacing and some shapes, and derives the rest. |
| Libertinus Math (not stored; outlines in `../scripts/draft_letterlike.py`) | The Libertinus Project Authors, 2012–2024 ([alerque/libertinus](https://github.com/alerque/libertinus)) | OFL 1.1 | The mathematical Fraktur 𝔐 𝔓 𝔖 𝔭. |

Design inputs that preserve accepted drawings outside the masters (so a
generator can rebuild them) live in `../scripts/data/` with their own
READMEs: `aleph/` (Italic and Bold Italic ℵ, derived from Old Standard),
`italic-i/` (the lighter Italic I), `oldstyle-italic/` and
`oldstyle-regular/` (the old-style figures).

## Comparison only

These are never copied into the fonts. They are downloaded at pinned
versions (`../scripts/data/reference-inputs.json`) to compare spacing,
kerning, weights and shaping against.

| Font or data | Source | Used by |
|---|---|---|
| Libertinus Serif (4 styles) | Libertinus release archive | spacing and pair comparisons, Greek and Cyrillic tests |
| Charis SIL (4 styles) | SIL release archive | the same |
| EB Garamond, GFS Didot, Bodoni Moda | Google Fonts repository, pinned commit | spacing ranges (`scripts/quality/`) |
| UDHR texts | unicode-org/udhr, pinned commit | shaping and coverage tests |

The reference fonts are a calibrated range for judging Myia Didot, not a
target to copy.
