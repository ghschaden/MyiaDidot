FONTLOG for Myia Didot
======================

This file provides detailed information on the Myia Didot font software.
This information should be distributed along with the Myia Didot fonts and
any derivative works.


Basic Font Information
----------------------

Myia Didot is a derivative of Theano Didot by Alexey Kryukov, part of the
Theano Classical Fonts (https://github.com/akryukov/theano). Theano Didot
is a Didot-style face for Greek (with the full polytonic set), Latin and a
basic set of Cyrillic.

Myia Didot aims to extend it to complete coverage of Latin-script
alphabets, Greek and basic Cyrillic, and to add Italic, Bold and Bold Italic
styles as well as true small capitals.

Because the Theano fonts carry "Theano" as a Reserved Font Name, this
derivative is published under a different name, as the SIL Open Font
License requires.
